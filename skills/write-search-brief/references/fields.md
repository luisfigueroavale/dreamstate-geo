# Fields

Call `knowledge.context.resolve` for the offer, the proof, and the never-claim list. Point at the pages. Fill `reader` from `audience.local/ideal-reader.md` only when that file is filled. If it is blank, stop.

`answer` is the sentence the page will open with, in 60 words or fewer. `primary_keyword` is the wording the group shares. `conversion_link` is a path the owner already uses. Do not invent a path.
