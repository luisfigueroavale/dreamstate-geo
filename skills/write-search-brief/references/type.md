# Page type

Pick one template.

- `briefs/compare.md` when the query compares us with one named product.
- `briefs/roundup.md` when the query is a list or a pricing guide.
- `briefs/how-to.md` when the query is a task.

Copy it to `work/briefs/<slug>.md`. Set `page_type` to the same word. The wrong template is a failed gate later. Do not mix two types in one file.
