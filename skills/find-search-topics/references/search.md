# Paid search

Use `visibility.research.web_search` only for a gap the owner named, or a group that has impressions and no page. The cost is 4 credits a call. `query` is required. Optional fields are `max_results` (1 to 10, default 10), `include_text`, `include_domains`, and `category`.

Quote first, wait for the owner's yes. Show the quote, then wait. Count each call against the weekly cap in `search.local/plan.md`. If the cap is blank, stop and ask for a number. Do not assume a cap of zero, and do not assume the cap is unlimited.
