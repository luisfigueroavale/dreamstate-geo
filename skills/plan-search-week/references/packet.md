# Packet

Each packet is four lines.

- Goal: the page or the fix, in one sentence.
- Inputs: file paths and the day report path. No pasted secrets.
- Skill: one skill name from this repo.
- Guardrails: quote first, wait for the owner's yes, on any paid id the skill names. Merge waits for a yes. Do not invent a number.

Write the packets to `work/week/<date>.md`.
