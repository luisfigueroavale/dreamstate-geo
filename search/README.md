# Search workspace

These files are blank templates. Copy the folder to `search.local/` and fill the copy.

```sh
cp -r search search.local
```

Git ignores `search.local/`. Do not put a real site, a real query, or a real customer in this folder.

| File | What it holds |
|---|---|
| [plan.md](plan.md) | Focus, priority pages, the order of bets, the leave-alone list |
| [targets.json](targets.json) | The six numbers we want to move |
| [changes.json](changes.json) | One marked example of a change record |
| [prompts.md](prompts.md) | How the tracked prompt set is chosen and revised |

Durable history does not stay in the JSON files. Weekly notes and verdicts go to Dreamstate Knowledge, in the seat folder `18 Search & AI Answers`.
