# Glossary

Plain meanings for this desk.

| Term | Meaning |
|---|---|
| GEO | Generative engine optimization. Work that gets a page quoted in AI answers, and found in Google. |
| Answer engine | A product that searches the web and replies with a passage, such as ChatGPT, Gemini, Perplexity, or a Google AI Overview. |
| Impression | A time the page was shown in search results. It is not a click. |
| Click | A time someone opened the page from search. |
| Position | Where the page sat in the results. 1 is the top. 11 to 20 is page two. |
| Citation | A link an AI answer shows next to a passage. |
| Mention | The brand or the page named in an AI answer, with or without a link. |
| Tracked prompt | A question you ask an answer engine on a schedule. This desk uses the 25 prompt cap. |
| Probe | One paid run of the tracked prompts. Quote it first. |
| Control group | Unchanged pages of the same type, measured on the same days as the page you edited. |
| Brief | The plan for one page. The page is not drafted until the brief check says ready. |
| Packet | Four fields for the Chief of Staff: Goal, Inputs, Skill, Guardrails. |
| Company Context | Dreamstate pages for the buyer, the proof, and the voice. Do not paste them into this repo. |
| Knowledge | Dreamstate history. Weekly notes and verdicts go to the seat folder `18 Search & AI Answers`. |
| Page type | `compare`, `roundup`, or `how-to`. The control group stays inside one type. |
| Never claim | A sentence the owner forbids. It fails the review even if a source could support a similar line. |
