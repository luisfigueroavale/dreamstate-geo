# Sample site

Fictional company. Cedar Line is not real. Maple Sheet is not real. This is not Dreamstate data, and it is not a customer.

| File | What it is |
|---|---|
| [brief.md](brief.md) | A comparison brief that passes `scripts/brief-check.mjs` |
| [brief.json](brief.json) | The same brief as JSON, for the schema check |
| [page.md](page.md) | A page that passes `scripts/page-lint.mjs` |
| [lint-report.json](lint-report.json) | The lint result stored from that run |
| [review.md](review.md) | A PASS verdict from the rubric |
| [reading.json](reading.json) | One fictional experiment reading |

Do not copy these numbers into a live plan. They were written so the checks have a worked example.
